# Telegram Bot - Мониторинг удаленных сообщений

Бот для мониторинга удаленных и отредактированных сообщений в Telegram чатах.

## 🎯 Возможности

- ✅ Отслеживание всех сообщений в чатах
- ✅ Сохранение медиа-файлов (фото, видео, голосовые сообщения, документы)
- ✅ Уведомления об удаленных сообщениях
- ✅ Уведомления об отредактированных сообщениях
- ✅ База данных SQLite для хранения истории
- ✅ Автоматическое скачивание медиа-файлов

## 📋 Требования

1. **Telegram Premium** подписка
2. Бот должен быть добавлен как **Business Bot** в настройках Telegram:
   - Настройки → Telegram для бизнеса → Боты
3. Python 3.8 или выше
4. Библиотеки из `requirements.txt`

## 🚀 Установка

1. Клонируйте репозиторий:
```bash
git clone <repository_url>
cd tg-del-bot
```

2. Создайте виртуальное окружение (рекомендуется):
```bash
python3 -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Создайте файл `.env` на основе `env.example`:
```bash
cp env.example .env
```

5. Отредактируйте `.env` и укажите:
   - `TELEGRAM_BOT_TOKEN` - токен бота от @BotFather
   - `ADMIN_ID` - ваш Telegram ID (можно узнать у @userinfobot)

## 🔧 Настройка Business Bot

1. Откройте Telegram
2. Перейдите в **Настройки** → **Telegram для бизнеса**
3. В разделе **Боты** добавьте вашего бота
4. Бот начнет получать все сообщения из личных чатов

## ▶️ Запуск

```bash
python bot.py
```

Бот начнет работать и мониторить сообщения. Все удаленные и отредактированные сообщения будут отправляться вам в личные сообщения с ботом.

## 🔒 Безопасность

- ⚠️ **НИКОГДА** не коммитьте файл `.env` в репозиторий
- ⚠️ Не публикуйте токен бота в открытом доступе
- ⚠️ База данных и загруженные файлы по умолчанию игнорируются Git

## 📝 Функционал

### Отслеживание сообщений
Бот автоматически сохраняет все сообщения, которые приходят в Business чаты:
- Текст сообщений
- Медиа-файлы (до 20 МБ)
- Информация об отправителе
- Дата и время

### Удаленные сообщения
Когда сообщение удаляется, бот отправляет вам:
- Имя отправителя
- Тип контента
- Дата создания
- Текст сообщения
- Медиа-файл (если был)

### Отредактированные сообщения
Когда сообщение редактируется, бот отправляет вам:
- Имя отправителя
- Старую версию текста
- Новую версию текста

## 🛠️ Разработка

Для разработки рекомендуется использовать виртуальное окружение и следовать PEP 8 стандартам кодирования.

## 📄 Лицензия

Этот проект предназначен для личного использования. Используйте ответственно и в соответствии с правилами Telegram.

## ⚠️ Важные замечания

- Бот работает только с Business чатами (личные чаты через Telegram Business)
- Файлы размером более 20 МБ не сохраняются
- База данных хранится локально в файле SQLite
- Медиа-файлы сохраняются в папке `downloads/`

## 🐛 Известные проблемы

- Video notes отправляются отдельно от текста (ограничение Telegram API)
- Медиафайлы с таймером не сохраняются (ограничение Telegram API)
