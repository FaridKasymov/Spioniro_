# 🕸️ Spioniro_ 

**Это высокотехнологичный терминал мониторинга для Telegram Business API. Система предназначена для скрытого логирования, анализа и восстановления данных из бизнес-чатов в реальном времени.**

## ⚡️ Ключевые возможности

*   **Intercept Engine**: Автоматический перехват и сохранение всех входящих бизнес-сообщений.
*   **Incident Control**: Специальный мониторинг удаленных и отредактированных сообщений.
*   **History Trace**: Уникальная система отображения правок — вы видите и старый текст (зачеркнуто), и новый вариант.
*   **Interlocutor Analytics**: Динамический ТОП самых активных собеседников по количеству инцидентов.
*   **Deep Media Access**:
    *   ***Secret Gallery***: Просмотр удаленных фото и видео в полноэкранном режиме внутри Mini App.
    *   ***Voice Intercept***: Встроенный плеер для прослушивания удаленных голосовых сообщений.

*   **Smart Search**: Мгновенный поиск по тексту сообщений конкретного собеседника "на лету".
*   **Cipher Core**: Все текстовые данные в базе данных зашифрованы алгоритмом **AES-128 (Fernet)**.

## 🛠 Технологический стек

*   **Core**: Python 3.10+, Aiogram 3.x (Business API Support).
*   **API Layer**: FastAPI + Uvicorn.
*   **Database**: SQLite с асинхронным драйвером `aiosqlite`.
*   **Security**: Cryptography (Fernet encryption).
*   **Frontend**: Vanilla JavaScript (Telegram Web Apps SDK), CSS3 (Cyberpunk/Terminal style).

## 📦 Развертывание (Local Setup)

### 1. Установка зависимостей
```
pip install -r requirements.txt
```
### 2. Настройка окружения
Создайте файл `.env` в корне проекта и добавьте следующие переменные:
```
BOT_TOKEN=ваш_токен
ADMIN_ID=ваш_телеграм_id
ENCRYPTION_KEY=ваш_ключ_fernet
WEB_APP_URL=ссылка_на_ваш_терминал
```
### 3. Запуск системы
Для полноценной работы необходимо запустить два процесса:

#### Запуск бота:

```
python bot.py
```
#### Запуск сервера админ-панели:

```
uvicorn frontend.api:app --host 0.0.0.0 --port 8000
```
## 📂 Архитектура проекта
`bot.py` — обработка событий Business API и шифрование.

`security.py` — логика шифрования/дешифрования данных.

`frontend/api.py` — серверная часть админ-панели.

`frontend/index.html` — визуальный интерфейс терминала.

`business_logs.db` — зашифрованное хранилище данных.

`downloads/` — локальное хранилище медиафайлов.
